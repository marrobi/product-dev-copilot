# GOV.UK Digital Service Compliance Rules

## Service Standard

### 14 Points of the GOV.UK Service Standard
1. Understand users and their needs
2. Solve a whole problem for users
3. Provide a joined up experience across all channels
4. Make the service simple to use
5. Make sure everyone can use the service
6. Have a multidisciplinary team
7. Use agile ways of working
8. Iterate and improve frequently
9. Create a secure service which protects users' privacy
10. Define what success looks like and publish performance data
11. Choose the right tools and technology
12. Make new source code open
13. Use and contribute to open standards, common components and patterns
14. Operate a reliable service

## Accessibility

### Public Sector Bodies Accessibility Regulations 2018
- WCAG 2.1 Level AA compliance
- Accessibility statement required
- Regular testing and audits
- Disproportionate burden exemption available

## Security

### Government Security Classifications
- OFFICIAL: Routine business
- SECRET: Very sensitive information
- TOP SECRET: Exceptionally sensitive

### Cyber Essentials
- Mandatory for government contracts
- Basic security controls

## Data Protection

### UK GDPR & Data Protection Act 2018
- Privacy by design
- Data Protection Impact Assessments (DPIA)
- Information Commissioner's Office (ICO) compliance

## Technology Standards

### Technology Code of Practice
- Use open standards
- Use cloud first
- Make things accessible
- Make data open
- Use open source
- Use common platforms

### API Standards
- RESTful design
- OAuth 2.0 for authentication
- JSON for data exchange
